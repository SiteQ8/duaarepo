# Contributing to Dua Collection

## Adding New Duas

All duas must include:
1. **Arabic text** — from an authenticated source
2. **English translation** — accurate and clear
3. **Source citation** — Quran (surah:ayah), Hadith (collection name), or scholarly reference

Format in the DUAS array:
```javascript
{cat:'category', ar:'Arabic text', en:'English translation', src:'Source reference'}
```

## Categories
Use existing category IDs: quran, morning, evening, daily, protection, forgiveness, praise, travel, food, sleep, distress

## Accuracy Standards
- Quran text must match the Uthmani Mushaf
- Hadith must cite the collection (Bukhari, Muslim, etc.)
- Translations should be clear and faithful to the Arabic meaning

## Submitting
1. Fork → branch → edit `docs/index.html` → test → PR
